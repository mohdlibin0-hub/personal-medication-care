Personal Medication Care – Storyboard

Problem

People may forget to take their medicines at the correct time. The Personal Medication Care system helps users manage medicines, set reminders, and track their medication history.

Story 1 – User Registration

User Action: User creates an account by entering personal details.

System Response: The system validates and stores the user’s details.

Progress: Completed

Story 2 – Add Medicine

User Action: User enters medicine name, dosage, and medicine time.

System Response: The system stores the medicine details.

Progress: Completed

Story 3 – Medicine Reminder

User Action: User sets a reminder for taking medicine.

System Response: The system sends a notification at the scheduled time.

Progress: In Progress

Story 4 – Mark Medicine Status

User Action: User selects Taken or Missed after the scheduled medicine time.

System Response: The system records the medication status.

Progress: To Do

Story 5 – Medication History

User Action: User opens the medication history section.

System Response: The system displays previous medication records, including taken and missed medicines.

Progress: To Do

Conclusion

The Personal Medication Care system helps users manage their medicines, receive timely reminders, and maintain their medication history.
