Personal Medication Care – Test Cases

TC01 – User Registration

Test Objective: Verify user registration.

Input: Valid username, email and password.

Expected Result: User account should be created successfully.

Status: Pass

TC02 – Invalid Registration

Test Objective: Check registration with invalid details.

Input: Invalid email address.

Expected Result: System should display an error message.

Status: Not Tested

TC03 – Add Medicine

Test Objective: Verify adding medicine details.

Input: Medicine name, dosage and time.

Expected Result: Medicine details should be saved successfully.

Status: Pass

TC04 – Empty Medicine Details

Test Objective: Check medicine submission with empty fields.

Input: Medicine name and dosage left empty.

Expected Result: System should display a validation message.

Status: Not Tested

TC05 – Set Medicine Reminder

Test Objective: Verify medicine reminder functionality.

Input: Select medicine and reminder time.

Expected Result: System should send a notification at the scheduled time.

Status: In Progress

TC06 – Mark Medicine as Taken

Test Objective: Verify taken medicine status.

Expected Result: System should record the medicine as Taken.

Status: Not Tested

TC07 – Mark Medicine as Missed

Test Objective: Verify missed medicine status.

Input: Select Missed.

Expected Result: System should record the medicine as Missed.

Status: Not Tested

TC08 – View Medication History

Test Objective: Verify medication history.

Input: Open medication history.

Expected Result: System should display previous medication records.

Status: Not Tested

TC09 – Update Medicine Details

Test Objective: Verify updating medicine information.

Input: Change medicine dosage or reminder time.

Expected Result: Updated details should be saved successfully.

Status: Not Tested

TC10 – Delete Medicine

Test Objective: Verify deleting a medicine.

Conclusion

The test cases help verify the functionality, accuracy and reliability of the Personal Medication Care system.
